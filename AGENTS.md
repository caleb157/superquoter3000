- Tasks link to at most one thing via association_type/_id/_label (product_id deprecated; inquiry_id/customer_id kept in sync for existing views) — new link kinds need no schema change.
- Recurring tasks are one living row: completing logs a done copy and rolls due_date (src/lib/task-recurrence.ts).
- Odoo task events: task_automation_rules → odoo-task-webhook (admin token in task_automation_config); Odoo pushes, HQ never polls. HQ automations (inquiry created, customer→Lead) fire from DB triggers (run_hq_task_automation) sharing the same rules.
- Master Analytics actuals come only from the latest analytics_snapshots row (odoo-analytics-sync, manual Refresh); pipeline is computed live (src/lib/master-analytics.ts).
- Pipeline certainty: inquiry override → booked 100%/cancelled 0% → repeat default → Settings default_certainty_pct (src/lib/projection-defaults.ts); stage weighting retired.
- Projections are PV-only: other-entity sales pay PV via inter-entity deposit/balance; missing FOB/man-hours fall back to live costing (src/lib/pipeline-live.ts).
- Analytics opening cash = sum of Odoo asset_cash in the snapshot; capacity = LaborTrax /api/public/capacity-forecast read straight from the snapshot (matches LT incl. WO overrides).
- Costing Intake (src/lib/costing-intake.ts) is the one bulk-costing spreadsheet format (Import creates, Bulk Editor updates); writes raw inputs only — the engine derives the rest.
- Costing Workspace (/inquiry/:id/costing) is the one costing place (old grid routes redirect): in-memory bundle (src/lib/costing-workspace.ts), recompute per edit, persistResolvedCosting. Cells carry data-grid/data-row/data-col; keyboard nav is a DOM lookup (costing-workspace/cells.tsx); sizes are separate W/D/H columns.
- Contribution = (net profit + indirect OH absorbed) ÷ FOB, indirect share carries cost of capital (src/lib/costing-workspace.ts); bought-in items → contribution = NPM.
- Iron Weight: math in src/lib/iron-weight-core.ts (untouched); draft in localStorage, builds in iron_builds (free-text SKU + label); photo estimate drafts parts only.
- Task postpone (1d/1w/1mo) counts from later of today and due date (src/lib/task-postpone.ts); saves with Undo.
- Running inches = longest + shortest side (Wood Table: long side, or override); finishing ₹/RI × % wood, packaging 0.015 MH/RI (autoLaborEstimate, costing-engine.ts, is_auto_estimated only).
- Inquiry clock: received (or created same-day) → first saved quote or hand-set quoted_date; amber 3d, red 7d, grey inactive; repeats have no clock, out of timing KPIs (src/lib/inquiry-clock.ts).
- Quotes generate in one click (src/lib/quote-rough.ts: live prices, name-sorted, last Incoterm); edit after — no review dialog.
- Sent quotes never change: first save copies to a new draft (Q-…-v2 on quote_snapshots, src/lib/quote-versions.ts).
- Samples: sample_requests (per batch) + samples lines; pending=requested, completed=received. Clock = request date → all live lines received (src/lib/sample-requests.ts); the samples trigger sets product sample_stage; inquiry_received_rfs log retired.
- Analytics timing KPIs read the inquiry-strip clocks (src/lib/timing-kpis.ts): medians of clocks stopped in the period, 6-mo trend, drill-down.
- Repeat orders: "Repeat of…" clones products recosted today, flags repeat_order → 80% default certainty, own cash-flow line (src/lib/repeat-order.ts).
- Photo intake: estimate-product drafts from photo + W×D×H as Costing Intake inputs (src/lib/photo-intake.ts); flagged "estimated" until Mark checked.
- Cost history (product_cost_history, src/lib/cost-history.ts): written from shared save paths only when cost/price/rate/part moved, with a plain-words reason; read by the Cost history tab + re-quote warning; never stored on quote_snapshots (get-quote serves those).
- Live rates (live-rates-sync → global_settings.live_*) always drive costing (src/lib/live-rates.ts): inquiry overrides win, failed source keeps last good value, sent quotes keep frozen rate; manual rate fields removed.
- Task Odoo order links: live search (odoo-order-search); store only order number + label.
- Breakeven: math in src/lib/breakeven.ts; contribution = gross margin (price − bought-in/MO materials); live defaults from 12-mo finished Odoo orders; localStorage-only edits, Reset to live.
- Send to Odoo: reviewed BOM from resolved COGS rows (src/lib/odoo-bom.ts); Odoo read live (odoo-product-lookup), only picked links kept (odoo_component_links by category+name); odoo-bom-push (admin) reuses SKUs, never a 2nd BOM — re-run safe; inquiry batch shares item decisions (applyShared). PREFIX_RULES: PIC/PMC/TMB/CHM/HRD tracked; SCR/LBL/ACC/FCR/PKS non-inventory; ADH/TAP/SND/CON/SUB/INH own categories; packaging/consumables prefix from line name; prefixes fill PREFIX-ITEM (hand-typed untouched); raw pieces PRODUCT_SPECIFIC.
- Pcs/MC: one master carton plan (planMasterCarton, src/lib/calculations.ts) drives costing + packed CBM (orientations tried, upright wins ties; hand layout over search; per-MC override keeps carton size).

Math in src/lib/dkt-cashflow.ts + dkt-amazon.ts; never auto-draws credit.
